Raahi project hub

Raahi is a FastAPI and vanilla-JS web app on Cloud Run, using Gemini 3.8 Flash on Vertex AI. Its hero feature, Tutorial Rescue, watches an old YouTube tutorial, re-checks each step against today's docs with Google Search grounding, and shows sources.
