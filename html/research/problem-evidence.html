Problem evidence: old tutorials break

Viewers of old software-setup tutorials report that steps no longer work far more often than viewers of recent ones. Creators rarely reply.

Source: research/problem-validation/results.json (authority), research/problem-validation/REPORT.md. Cohort B_old: 144 setup tutorials published 2019-2022, median 1,145,030 views. Cohort B_new: 151 tutorials from the last 6 months.

Read the second chart with care: 66.0% of old videos still get fresh comments, so the audience is still arriving. The reply rate of 28.8% means most problem comments get no creator answer.

Method

  • YouTube Data API v3 for video lists, metadata and top-level comments.
  • Cohorts by publish date and topic: B_old (2019-2022) and B_new (last 6 months), same kind of software-setup query.
  • A regex codebook tags each comment, for example OUTDATED, STILL_OK, STUCK, LINK_DEAD. The cohort numbers count videos with at least one tagged comment.
  • Commenter identities are not stored.

Source: results.json fields; REPORT.md. The regex codebook is in research/problem-validation/analyze.py. Query list and comment counts (24,109 old, 10,208 new) are in results.json.

Caveats stated in the report

  • The OUTDATED regex used for the 45.8% / 14.6% numbers has not been hand-checked for precision. In a separate sample (comments on 94 videos from YouTube Creators, Creator Insider, vidIQ and Think Media), the same kind of "outdated" tag was about 50% precise on 13 matches, so treat the absolute rates as upper bounds; the old-vs-new gap is the stronger signal.
  • Counts are API snapshots; comments react to what the sampled channels posted.
  • The report calls this a real viewer pain that creators do not voice themselves.
  • Dead-link tools already exist with near-zero revenue, per the report (one example: $119 all-time).
  • Tutorial Rescue evals were chosen from viewer comments by hand: 47 candidates scanned, 16 kept, keywords frozen before the first run. See eval/CASES.md. Results will be on the eval page once it is written.
